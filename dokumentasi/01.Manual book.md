## 🛠️ LANGKAH 1: MENYIAPKAN FOLDER PROYEK & DEPENDENSI

Buka terminal (CMD / PowerShell / Git Bash) di laptop baru, lalu jalankan perintah berikut secara berurutan:

### 1. Download Project dari GitHub
```bash
git clone https://github.com/alfarezaung762-bot/Penggajian.git
cd Penggajian
```
> 📌 **Fungsi:** Mengunduh seluruh kode program dari GitHub dan masuk ke folder utama proyek.

### 2. Install Dependensi Paket Node.js
```bash
npm install
```
> 📌 **Fungsi:** Mengunduh semua modul pendukung aplikasi (Next.js, React, Prisma, Tailwind CSS, dll).

### 3. Masukkan Berkas Konfigurasi `.env`
Salin file **`.env`** (tersedia di link Google Drive) dan letakkan di folder utama proyek (sejajar dengan file `package.json`).

**Contoh isi file `.env` untuk database lokal:**
```env

CLOUDINARY_CLOUD_NAME=dqbjfbuoo
```

> 💡 **Catatan:** Ganti `12345` pada `DATABASE_URL` dengan password postgres pgAdmin di laptop Anda.

### 4. Generate Prisma Client
```bash
npx prisma generate
```
> 📌 **Fungsi:** Membangun jembatan data (*Prisma Client*) agar kode TypeScript & Next.js bisa mengenali tabel database.

## 🗄️ LANGKAH 2: MENYIAPKAN DATABASE (PILIH SALAH SATU)

Pilih salah satu metode di bawah ini untuk mengisi database di laptop baru:

---

### 🔹 CARA A: Restore dari File Backup SQL pgAdmin (Manual)
1. Buka **pgAdmin 4** di laptop Anda.
2. Klik kanan pada **Databases** ➔ pilih **Create** ➔ **Database...**
3. Masukkan nama database: **`Penggajian`** ➔ klik **Save**.
4. Klik kanan pada database `Penggajian` yang baru dibuat ➔ pilih **Restore...**
5. Pilih file `backup_penggajian.sql` (dari Drive/Flashdisk) pada baris *Filename* ➔ klik **Restore**.

---

### 🔹 CARA B: Seeding Otomatis Prisma (Paling Praktis & Cepat — RECOMMENDED)
Jika tidak menggunakan file backup SQL atau jika data belum muncul, Anda bisa mengisi ulang database secara otomatis lewat terminal:

1. **Buat Struktur Tabel Otomatis:**
   ```bash
   npx prisma db push
   ```
   > 📌 **Fungsi:** Membuat 15 tabel database lengkap dengan relasinya di PostgreSQL secara otomatis.

2. **Isi Data Karyawan, Absensi, & Gaji (Seeding):**
   ```bash
   npx tsx prisma/seed.ts
   ```
   > 📌 **Fungsi:** Otomatis mengisi akun karyawan demo `budi`, akun `hrd`, `admin`, 30 karyawan baru, foto avatar profil, riwayat absensi multi-bulan, dan slip gaji.

## 🚀 LANGKAH 3: MENJALANKAN APLIKASI

Jalankan perintah berikut untuk menyalakan aplikasi di laptop:

```bash
npm run dev
```
> 📌 **Fungsi:** Menyalakan server lokal aplikasi.
>
> 🌐 Buka browser dan akses alamat: **`http://localhost:3000`**

## ❓ TROUBLESHOOTING (JIKA DATA TIDAK MUNCUL / KOSONG)

Jika aplikasi terbuka tetapi data karyawan masih kosong atau terjadi error database:

1. Pastikan password PostgreSQL pada file `.env` sudah sesuai dengan pgAdmin laptop Anda.
2. Buka terminal dan jalankan 2 perintah ini:
   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```
3. Refresh halaman di browser. Seluruh data 31 karyawan dan riwayat gaji akan langsung muncul kembali!
